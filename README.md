# AI Website Platform

AI-платформа для создания, редактирования и продвижения сайтов.

## Основная идея

Платформа объединяет ИИ-агентов, которые совместно выполняют задачи по созданию и развитию сайтов.

### MVP

1. Регистрация пользователя
2. Создание проекта
3. Ввод информации о бизнесе
4. Формирование структуры сайта
5. Создание страниц и блоков
6. Генерация дизайна и контента
7. Предпросмотр
8. Проверка качества
9. Подключение внешнего CMS
10. Безопасная публикация

### Тарифы

- Создание сайта
- Продвижение
- MAX

### AI-агенты

- Orchestrator Agent
- Business Agent
- Design Agent
- Content Agent
- Developer Agent
- QA Agent

В дальнейшем:

- SEO Agent

- Integration Assistant
- другие специализированные агенты

## Архитектурный принцип

Основой платформы является универсальная модель сайта (Website Model).

Она не зависит от конкретной CMS и позволяет работать через адаптеры с:

- Tilda
- Bitrix
- WordPress
- собственным Website Engine
- другими системами в будущем
