# 1. ❌ Node.js

### Что это?

**Node.js — это среда, которая позволяет запускать JavaScript не только в браузере, но и непосредственно на компьютере/сервере.**

Обычно JavaScript работает здесь:

```text
Chrome / Safari
      ↓
JavaScript
      ↓
Веб-страница
```

Node.js позволяет запускать JavaScript здесь:

```text
Mac / Server
      ↓
Node.js
      ↓
JavaScript / TypeScript
```

### Зачем нам?
