# Security policy — Kleo

Статус: Security Foundation, локальная разработка. Публичного сервиса, регистрации и production-инфраструктуры пока нет. Найденная уязвимость не публикуется в открытом issue, архиве переписки, общем чате или share-ссылке.

## Как сообщить о проблеме

Сообщите владельцу проекта Кириллу через уже согласованный приватный канал. Отдельный адрес для security reports пока не создан; выдуманный email не используется. Передайте краткое описание, затронутую версию/файл, влияние и воспроизведение на искусственных данных. Не передавайте действующие ключи, пароли, персональные данные и содержимое `.env`. Если приватный канал ещё не согласован, сначала согласуйте его с владельцем. Не проверяйте уязвимость на чужих аккаунтах.

Security issue: доступ к чужому проекту, обход прав или approval, утечка credentials/логов, неразрешённый tool call, SSRF, выполнение недоверенного кода, подделка webhook, неконтролируемый расход AI, опасная зависимость или конфигурация.

## Секреты и ротация

Локально `.env` допустим только вне Git и с правами владельца `600` на Unix. Smoke проверяет владельца, режим и отсутствие symlink. В staging/production секреты не размещаются в `.env` рядом с кодом: подключается серверный SecretProvider к выбранному менеджеру секретов с минимальными правами. LocalSecretProvider запрещает production-режим и служит только разработке/тестам. Запрещено добавлять действующие значения в `.env.example`, логи и историю Git.

При подозрении на утечку сначала отозвать ключ у провайдера, затем выпустить новый с минимальными правами, обновить серверное хранилище и проверить доступ. Удаление строки или коммита не отменяет утечку. Проверить usage, связанные интеграции, журнал и историю репозитория; очистку истории согласовать отдельно, поскольку она меняет общую историю. Подробный процесс — [Incident response](docs/INCIDENT-RESPONSE.md).

## Проверки разработчика

`npm run typecheck`, `npm test`, `npm run security:check`, `npm run security:audit`, `git diff --check`. Audit использует сеть реестра npm; платные AI API не вызываются. Не применять `npm audit fix --force` автоматически. Сканер секретов — эвристика текущих файлов, включая архивы, а не доказательство отсутствия секретов и не скан всей Git history. Обнаруженные строки не выводятся.

Границы и честный статус: [Security Foundation](docs/SECURITY-FOUNDATION.md), [Checklist](docs/SECURITY-CHECKLIST.md), [Threat model](docs/THREAT-MODEL.md). Любые проверки здесь не заменяют отдельного аудита перед публичным пилотом.
